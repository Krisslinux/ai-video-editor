# Security policy

Please do not post exploit details or credentials in public issues. Use GitHub's private vulnerability reporting for this repository if enabled; otherwise contact the maintainer privately through their GitHub profile before publishing details. Supported security maintenance currently targets the development branch only. The renderer is sandboxed with named IPC; imported media and AI responses remain untrusted. Do not send private media or project data in diagnostics. Credential tokens use OS secure storage when available and are refused without it.
