Sentry: the official Electron SDK is installed with an opt-in, main-process-only diagnostic path. The UI preference is stored in settings and read before SDK initialization, but a restart after changing it has not been checked with an external Sentry project. No external Sentry project is configured, so service delivery remains unverified.
