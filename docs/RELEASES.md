# Release and installer status

No versioned release exists. A local unsigned NSIS development installer was built on Windows from the 9.0.2 Gyan full GPLv3 tools with the package's license/build information and a source reference. It is 243,104,141 bytes; SHA-256 `66E177D05AE6F7225DDCAA35691B67B5419754465E532EAF1C69D271F469BDB7`. The unpacked packaged app exported a 3.00 s 1280 × 720 H.264/AAC MP4 with the system `PATH` excluding FFmpeg. This build preceded the latest CodeRabbit fixes and was not clean-installed or distributed. User projects remain outside the app installation directory.

Before a release: record media tool version/configuration and licensing/source offer, produce and test a clean Windows NSIS install as a normal user (including uninstall preserving projects), verify first-run tool discovery and offline export, tag the source commit, attach checksums/notices/known limits, and record signing status. Safe updates, migration backups, rollback, macOS/Linux installation, and notarization remain planned. Publishing requires a separate deliberate action.

To prepare a local bundle, place the reviewed binaries and their actual license/source notice in `vendor/ffmpeg/<platform>/`. That directory is ignored by Git; packaging fails fast when the files are missing. The Gyan build includes external libraries, so a source URL and short notice alone are not a complete release compliance package. CI currently builds unpackaged Windows assets only. No signing credentials or release publishing run in untrusted pull-request jobs.
